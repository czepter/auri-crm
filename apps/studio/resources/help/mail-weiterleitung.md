Dein Studio hat genau eine eigene Adresse:

```
%inbound_address%
```

Damit Post an deine gewohnte Adresse hier ankommt, richtest du bei deinem
Mailanbieter eine Weiterleitung dorthin ein. Das Weiterleiten macht dein
Anbieter; ein Postfach wird hier nicht angebunden und kein Passwort abgefragt.

Vorne steht dein Anzeigename, kleingeschrieben und auf adressentaugliche
Zeichen gebracht. Änderst du den Anzeigenamen (%studio_name%), entsteht eine
andere Adresse, und Weiterleitungen auf die alte laufen ins Leere.

## Was mit einer eingehenden Mail geschieht

Antwortet jemand auf eine Nachricht, die du aus einem Projekt geschickt hast,
hängt sie sich an denselben Verlauf. Dafür trägt jede ausgehende Nachricht eine
eigene Antwortadresse; dein Kunde drückt in seinem Mailprogramm auf Antworten
und muss nichts weiter tun.

Alles andere wartet darauf, dass du es einem Projekt zuordnest.
Weitergeleitete Post gehört fast immer dazu: Sie nennt keinen Verlauf, den es
schon gibt.

Mail, deren Absender die Echtheitsprüfung nicht besteht, kommt in Quarantäne.
Du siehst sie, zuordnen lässt sie sich nicht.

Mail an eine Adresse, die zu keinem Studio gehört, wird verworfen, ohne dass
Absender, Betreff oder Text irgendwo gespeichert werden.

## Rotieren

Rotieren trifft mehr als die Adresse oben. Jede Nachricht, die du je aus einem
Projekt geschickt hast, trägt eine Antwortadresse aus demselben Geheimnis, und
die liegen in den Postfächern deiner Kunden. Auch jede Weiterleitung, die du
bei deinem Anbieter eingerichtet hast, zeigt danach auf eine tote Adresse.

Das ist die richtige Antwort auf eine Adresse, die in falsche Hände geraten
ist, und der falsche Weg zu allem anderen.
